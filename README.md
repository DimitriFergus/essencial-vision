# Essencial Vision Ótica — Site

Site da **Essencial Vision Ótica** (Instagram [@oticaessencialvision](https://instagram.com/oticaessencialvision)).

## Páginas
- `index.html`: início
- `catalogo.html`: catálogo de óculos com filtros e sacola (o pedido é finalizado pelo WhatsApp)
- `provador.html`: provador virtual 3D com câmera ou foto
- `lentes.html`: lentes e serviços
- `sobre.html`: sobre a loja
- `contato.html`: agendamento pelo WhatsApp

## Como editar
- Dados da loja (WhatsApp, endereço, e-mail): início de `assets/app.js`, objeto `LOJA`
- Produtos e preços: `assets/app.js`, lista `PRODUTOS`
- Cores e estilos: `assets/style.css`

> Modelos, preços e textos são exemplos para começar.
